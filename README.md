# 柠檬冰 · AI 增长实战课

三天线下实战课程的静态网站，包含 11 个连续三维场景、24 个课程模块和 32 张视觉示例。

## GitHub Pages

本仓库已是可直接发布的网页文件，无需安装依赖或运行构建。

在 Settings → Pages 中设置：

- Source：Deploy from a branch
- Branch：main
- Folder：/ (root)

点击 Save，等待 GitHub Pages 完成发布。`index.html`、`assets/` 和 `models-v3/` 必须一起保留，不要只上传 HTML 文件。`.nojekyll` 用于按静态文件原样发布。

网站资源使用相对路径，兼容仓库子目录。三维穿行、作品展和课程关注均在浏览器内运行。电脑端保留大画幅场景，手机端分开呈现场景与精简说明。主线以作品、系统与增长展开，具体模块按需查看；文字与镜头进度保持同步。课程重点仅保存在当前浏览器；当前开课日期、地点和正式报名方式待公布。

## 素材说明

作品展中含 8 张 AI 创作示例及 24 张摄影参考，均非学员作业或客户案例。摄影来源在作品详情中列明。摄影参考遵循 [Unsplash License](https://unsplash.com/license)。石材 PBR 材质来自 [Poly Haven](https://polyhaven.com/) 的 CC0 资源。三维建筑及工作台通过 Blender 为本项目建模，使用烘焙的接触明暗与 Meshopt 压缩；人物是课程照片合成层，远景为项目视觉素材。
