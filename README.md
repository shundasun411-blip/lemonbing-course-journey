# 柠檬冰 · AI 增长实战课

三天线下实战课程的静态网站，包含 11 个连续三维空间、32 个课程停留点、24 个模块和 32 张视觉示例。

## GitHub Pages

本仓库已是可直接发布的网页文件，无需安装依赖或运行构建。

在 Settings → Pages 中设置：

- Source：Deploy from a branch
- Branch：main
- Folder：/ (root)

点击 Save，等待 GitHub Pages 完成发布。`index.html`、`assets/` 和 `models-v3/` 必须一起保留，不要只上传 HTML 文件。`.nojekyll` 用于按静态文件原样发布。

网站资源使用相对路径，兼容仓库子目录。3D、自动漫游、作品展和课程选择均在浏览器内运行。课程重点仅保存在当前浏览器；当前开课日期、地点和正式报名方式待公布。

## 素材说明

作品展中含 8 张 AI 创作示例及 24 张摄影参考，均非学员作业或客户案例。摄影来源在作品详情中列明。摄影参考遵循 [Unsplash License](https://unsplash.com/license)。自然环境和石材材质来自 [Poly Haven](https://polyhaven.com/) 的 CC0 资源。三维建筑及工作台为本项目建模；人物是课程照片合成层。
